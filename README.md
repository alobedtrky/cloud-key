# Cloud Key Store V2

نسخة مطورة من متجر **Cloud Key | كلاود كي**، تعمل بواجهة عربية RTL وBackend خفيف بـ Node.js بدون مكتبات خارجية.

## التشغيل محليًا
```bash
npm start
```
ثم افتح `http://localhost:3000`، ولوحة الإدارة `http://localhost:3000/admin`.

## النشر
المشروع مناسب للاستضافات التي تدعم Node.js. اضبط المتغيرات التالية على الاستضافة:
- `ADMIN_USER`
- `ADMIN_PASSWORD`
- `SESSION_SECRET`
- `NODE_ENV=production`
- `PAYMENT_PROVIDER=demo`

> لا تضع أي مفاتيح دفع سرية داخل مجلد `public/`.

## ملاحظة مهمة
قاعدة البيانات الحالية موجودة في `data/db.json` لتسهيل التجربة. في استضافة مجانية قد تُفقد التغييرات عند إعادة تشغيل الحاوية، لذلك انقل الطلبات والمخزون لاحقًا إلى قاعدة بيانات دائمة قبل الاستخدام التجاري الحقيقي.
